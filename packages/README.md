# packages

Library and runtime packages consumed by the **yakka** plugin install root at `plugins/yakka` (the plugin is not a package and does not use the README field block).

| Directory | Purpose |
|-----------|---------|
| `hooklog` | Hook capture edge |
| `opencode-yakka-hooks` | OpenCode plugin |
| `yakka` | Go binary and catalogue |
| `yakka-analytics` | Static site embedded in the binary |
