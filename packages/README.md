# packages

Library and runtime packages consumed by the **workflow** plugin install root at `plugins/yakka` (the plugin is not a package and does not use the README field block).

| Directory | Purpose |
|-----------|---------|
| `hooklog` | Hook capture edge |
| `opencode-workflow-hooks` | OpenCode plugin |
| `workflow` | Go binary and catalogue |
| `workflow-analytics` | Static site embedded in the binary |
