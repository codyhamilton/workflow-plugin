## Goal

The analytics shell uses the solarized light and dark tokens, with an explicit override, and no stylesheet hex remains outside the token files.

## Contract

From DESIGN.md, Domain: Theme. Settled:

- Storage key `workflow-analytics-theme`. Values `system`, `light`, `dark`. An absent key means `system`.
- Document root carries `data-theme="light"` or `data-theme="dark"`. `system` follows `prefers-color-scheme`, including a later OS change. `light` and `dark` do not.
- Charts read computed tokens. They do not hard-code a color.
- Light: background `#fdf6e3`, surface `#eee8d5`, text `#657b83`, muted `#586e75`, border `#93a1a1`. Dark: background `#002b36`, surface `#073642`, text `#839496`, muted `#93a1a1`, border `#586e75`. Both: accent `#268bd2`, danger `#dc322f`.
- Series order, both modes: `#268bd2`, `#859900`, `#b58900`, `#cb4b16`, `#dc322f`, `#d33682`, `#6c71c4`, `#2aa198`.
- Body type stays `system-ui`. Space scale is 4, 8, 16, 24, 32. The shell uses it for its own padding and its control gaps. A route's own section gap is outside this contract.
- A notice, warning, or error uses `danger`, `surface`, `text`, and `border`. No new color token and no new hex.

## Changes

- Put the contract values on the CSS variables. Light is the default. Dark applies when `data-theme="dark"`, not only under `prefers-color-scheme`.
- `DEFAULT_TOKENS` is the light contract, including the series list. `theme.test.ts` follows that.
- The header has three controls, `data-testid="theme-system"`, `theme-light`, and `theme-dark`. Choosing one writes the storage key and sets `data-theme` without a reload.
- `watchScheme` also fires when `data-theme` changes, so charts that already subscribe to it repaint without a reload. Do not edit `EChart.svelte`.
- In every owned Svelte file, replace a hex in a `<style>` block with `var(--bg)`, `var(--surface)`, `var(--text)`, `var(--muted)`, `var(--border)`, `var(--accent)`, or `var(--danger)`. Drop hex fallbacks inside `var()`.
- Shell padding and the header's control gap use the space scale. Leave a route's own section gap as it is.
