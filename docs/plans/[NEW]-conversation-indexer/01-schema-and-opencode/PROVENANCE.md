## Agent Decisions

- **Fixtures are synthetic, not real session data.** Real session logs may contain private content (file paths, command output, model responses). The test corpus is generated by `tests/fixtures/build_fixtures.py`. This avoids accidental leaks via the test suite.
- **Opencode and claude-code share one parser, not two.** The format and storage path are identical. The parser is registered under both `tool='opencode'` and `tool='claude-code'` names. The `tool` column distinguishes the two at the row level.
- **Live session handling is deferred to v2.** A session is "complete enough to index" when its mtime is older than the most recent message timestamp. This is a v1 heuristic; live incremental support is a v2 feature.
- **`index_runs` records per-tool runs.** A `tool` column distinguishes per-tool runs from cross-tool reindexes (where `tool IS NULL`).
- **The malformed fixture is required from day one.** A test that exercises partial-parse behavior catches the most common production failure mode (corrupted JSONL rows) before it can surprise a user.
