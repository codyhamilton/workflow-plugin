# Proofs — durable analytics sink

Runnable from this directory:

```bash
./run_proofs.sh
```

| Script | Purpose |
|--------|---------|
| `dual_write_sink.py` | Lab dual-write helper (local JSONL + optional POST) |
| `mock_sink_server.py` | Single-request mock collector (port 18765) |
| `prove_cloud_egress.py` | HTTPS POST to `httpbin.org/post` (override with `WORKFLOW_ANALYTICS_EGRESS_PROBE_URL`) |
| `test_proofs.py` | unittest |

Validated artifacts (regenerated by `run_proofs.sh`):

- `validated/dual_write_result.json`
- `validated/mock_sink_received.jsonl`
- `validated/egress_cloud_result.json`

**Not** imported by `tools/driver/` on master.
